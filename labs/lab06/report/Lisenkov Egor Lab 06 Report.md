# Теоретическое введение

Обыкновенное дифференциальное уравнение описывает изменение переменной u по закону u′(t) = f(u(t), p, t) с начальным условием u(t0) = u0, где p — параметры модели, t — время. Численное решение задачи Коши выполняется методами пошагового интегрирования; в работе применяется классический метод Рунге–Кутты четвёртого порядка с фиксированным шагом, а контроль точности осуществляется сопоставлением с аналитическим решением, с первым интегралом системы или с сохраняющейся энергией. Пакет DifferentialEquations.jl предоставляет готовые решатели с параметрами точности abstol и reltol, однако прямая реализация метода Рунге–Кутты позволяет явно контролировать шаг и проверять решение, включая сравнение решений на сгущающихся сетках.

Модель экспоненциального роста u′ = a u с начальным условием u0 имеет аналитическое решение u(t) = u0 exp(a t) и служит базовым тестом численного метода. Динамическая система Лоренца является нелинейной автономной системой третьего порядка с параметрами σ, ρ и β; её решение неустойчиво на аттракторе, траектория хаотически переходит между двумя областями фазового пространства, образуя структуру в виде бабочки, поэтому длительная траектория не должна трактоваться как точный поточечный прогноз.

Модель Лотки–Вольтерры описывает взаимодействие двух видов типа «хищник–жертва» и обладает периодическими противофазными колебаниями численностей; фазовый портрет представляет замкнутую траекторию. Система имеет первый интеграл, сохраняющийся вдоль траектории, что позволяет контролировать точность численного решения: для системы x′ = 1.5 x − x y, y′ = −3 y + x y сохраняющаяся величина имеет вид H = x − 3 ln x + y − 1.5 ln y. Дискретный аналог модели задаётся нелинейным отображением, точки равновесия которого исследуются через собственные числа матрицы Якоби, а локальное поведение сравнивается с линеаризацией.

Модель Мальтуса x′ = (b − c) x описывает неограниченный рост изолированной популяции, логистическая модель x′ = r x (1 − x/K) ограничивает рост ёмкостью среды K и имеет точное решение K / [1 + (K/x0 − 1) e^(−r t)]. Модель эпидемии SIR делит популяцию на восприимчивых, инфицированных и переболевших с сохранением общей численности, а модель SEIR добавляет латентную группу, сдвигающую и сглаживающую пик инфицированных. Модель гармонического осциллятора x′′ + 2γ x′ + ω0 в квадрате x = 0 сводится к системе первого порядка; при γ = 0 энергия сохраняется и фазовая кривая является эллипсом, при γ больше нуля энергия убывает по закону E′ = −2γ y в квадрате, а фазовая кривая представляет сходящуюся спираль; значения γ = ω0 и γ больше ω0 дают критический и апериодический режимы затухания.

Аналитическое свойство системы состоит в том, что разность x − y = (x0 − y0) e в степени αt экспоненциально усиливается; проверка численного решения против этой формулы дала ошибку 1.03e-8, выведенную строкой PASS. Пояснено, что при равных начальных значениях обе популяции следуют одному логистическому уравнению с ёмкостью K = 20, а положительное равновесие (20, 20) является седлом, поэтому симметрия не означает устойчивости к любому возмущению, и модель не ограничивает рост победителя собственными ресурсами. На временном графике численность победителя к концу отрезка пятнадцати единиц времени достигает значения около 806.9 (рис. [-@fig:009]).

Завершили работу задания 7 и 8 по моделям гармонического осциллятора, сведённого к системе x′ = y, y′ = −ω0 в квадрате x − 2γy с циклической частотой ω0 = 2, начальными данными x0 = 1, y0 = 0 и отрезком времени [0, 20]. Для консервативного случая γ = 0 численное решение сверено с точным x = cos 2t с ошибкой 5.24e-8, а сохранение энергии E = (y в квадрате + 4x в квадрате)/2 выполнено с ошибкой 3.56e-9, что выведено строками PASS. Для затухающего случая γ = 0.2 решение сверено с точной формулой x = e в степени −γt [cos Ωt + (γ/Ω) sin Ωt] при Ω = √(4 − γ в квадрате), а убывание энергии проконтролировано условием отсутствия роста E′ = −2γy в квадрате.
